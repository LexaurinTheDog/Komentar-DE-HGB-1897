# HGB – Autorencharge §§ 484–503

Dieser begrenzte Arbeitsentwurf enthält genau 20 Vorschriften des Stückgutfrachtvertrags: §§ 484–503. Er behandelt Verpackung, Schiffstüchtigkeit, Ladeverantwortung, Begleitpapiere, Befrachterhaftung, Kündigung und Hindernisse, Fracht, Empfängerrechte, Pfandrechte und den Beginn der Güterschadenshaftung. Das Gesamtbuch bleibt unvollständig.
