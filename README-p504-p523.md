# HGB – Autorencharge §§ 504–523

Diese Charge enthält genau 20 Vorschriften: §§ 504–523 HGB. Erläutert werden Haftungsberechnung, außervertragliche Ansprüche, qualifiziertes Verhalten, Hilfspersonen und ausführender Verfrachter, Schadensanzeige und Verlustvermutung sowie Ausstellung, Inhalt, Beweiswirkungen und Abwicklung des Konnossements. Das Gesamtbuch ist noch unvollständig.
